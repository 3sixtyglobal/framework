# Interface: ICacheMetadata

Metadata for cached HTTPS modules.

## Properties

### downloadedAt {#downloadedat}

> **downloadedAt**: `number`

Timestamp when the file was downloaded.

***

### url {#url}

> **url**: `string`

Original URL of the cached file.

***

### size {#size}

> **size**: `number`

Size of the cached file in bytes.
